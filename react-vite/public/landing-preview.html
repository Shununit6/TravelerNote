Tell stories

Built with

A real full-stack app, not a static page.

Backend

  • Flask 3 + SQLAlchemy
  • Session auth + CSRF
  • SQLite (dev) / PostgreSQL (prod)
  • AWS S3 image upload
  • Hosted on Render

Frontend

  • React 18 + Vite
  • Redux Toolkit
  • React Router
  • Custom CSS, no UI framework
  • Responsive, mobile-first
